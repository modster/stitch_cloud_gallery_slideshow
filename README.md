# Photon Web

## Mission Statement
Making art with A.I. is cheating. It requires little skill, little time, little effort, and therefore has little value. For a human to produce a similar work of art much more skill, much more time, and much more effort is required, and therefore art made by humans *intrinsicaly* has much more value than the output of generative artificial intelligence.

###

[The Photon Suite of Apps](#the-photon-suite-of-apps), which includes Photon Web, have made it our mission to:

Guarantee that the photograph, video, and other media files created using this software are produced by actaul human being. created using our software is the work product of a human bieng. wihout the assistance of generative artificial intelligence.

Provide users with the means to verifiably prove that their creations were made with our software.

are handmade by an actual person.


Provide open source tool(s) designed for non technical users to verify if a media file was made with a Photon Suite app.

## How it works

When the user captures images or video`onCapture` a hash is created from the photograph, video, or other media using the device's hardware embeded keys.
